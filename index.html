Windows Desktop · Calendar

바탕화면은 단정하게.
일정은 한눈에.

DesktopDeck은 Windows 바탕화면의 아이콘 그룹과 일정을 관리하는 데스크톱 프로그램입니다. 로컬 일정과 Google Calendar의 여러 캘린더를 한 화면에서 표시할 수 있습니다.

주요 기능 보기Google 데이터 처리 확인

Windows 10/11 · WPF · .NET 8 · 프로그램의 기능은 버전에 따라 변경될 수 있습니다.

Features

데스크톱에서 관리하는 일상

바탕화면 아이콘 그룹

Windows 데스크톱의 아이콘을 그룹으로 정리하고 페이지를 관리합니다.

오늘 중심·월 단위 보기

오늘을 기준으로 여러 주를 확인하거나 월간 보기로 전환합니다.

Google Calendar 연결

한 Google 계정의 기본·보조 캘린더를 불러와 표시할 캘린더를 선택합니다.

일정 저장 대상 지정

새 일정의 기본 저장 캘린더를 지정하고 개별 일정마다 저장 대상을 선택합니다.

색상·투명도 설정

캘린더의 배경색, 투명도와 표시 방식을 조절합니다.

일정 편집

바탕화면에서 일정을 만들고 변경하거나 삭제할 수 있습니다.

Google 계정 연결 방법

DesktopDeck 캘린더 설정에서 Google 계정 연결 / 캘린더 불러오기를 선택하면 시스템 기본 브라우저에서 Google의 로그인·권한 승인 화면이 열립니다. 승인 후 여러 캘린더를 표시하고 일정별 저장 대상을 선택할 수 있습니다.

데이터 접근 안내

캘린더 목록 조회 및 일정 조회·생성·변경·삭제에 필요한 권한을 사용합니다. 인증 후 약 5분 간격으로 양방향 동기화를 시도할 수 있습니다. 동기화에 의해 Google Calendar의 일정이 변경되거나 삭제될 수 있습니다.
